Полностью опубликован исходный код модели, включая архитектуру, скрипты обучения и внутренние инструменты. Некоторые внутренние параметры и алгоритмы остались закрытыми.

Это повысит риски безопасности, снизит барьеры для конкурентов и может стимулировать развитие более защищенных систем. Также возможны новые стандарты защиты данных.
